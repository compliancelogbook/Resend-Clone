# Resend Landing Page Clone

## Running the Project

Run `pnpm dev` from the repository root to open the static React + Vite implementation. Use `pnpm check` to run TypeScript validation.

## Implementation Basis

This project reproduces the supplied `https://resend.com/` homepage reference using the provided screenshots, the public page structure, browser-observed runtime signals, recovered first-party public assets, and verified font files. The live source presents as a Next.js / Turbopack application. The implementation uses the project’s supplied React + Vite scaffold with Framer Motion for equivalent visibility and interaction behaviour.

## Key Files

| File | Purpose |
